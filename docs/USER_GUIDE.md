## Обзор {#обзор}

**RoomKanban** — настольная программа для небольшой команды: канбан-доска, сроки, файлы к задачам и быстрый обмен документами между сотрудниками.

Все данные отдела хранятся в **одной общей папке**, которую вы сами указываете при создании или входе в «комнату»:

- папка на сервере в локальной сети;
- синхронизируемая папка облака (OneDrive, Яндекс.Диск и т.п.);
- локальный диск или флешка (если отдел работает с одного носителя по очереди).

**Отдельный сервер не нужен:** коллеги видят одни и те же задачи, потому что программа на каждом компьютере читает и записывает данные в эту общую папку. При изменениях с другого ПК список обновляется автоматически; при необходимости можно принудительно обновить данные кнопкой **Обновить синхронизацию**.

На каждом рабочем месте устанавливается только программа; **папку комнаты** все используют одну и ту же.

## Возможности {#возможности}

| Область | Что умеет программа |
|--------|----------------------|
| **Комната** | Создание «комнаты» в выбранной папке, вход по списку сотрудников (без саморегистрации), несколько недавних комнат |
| **Канбан** | Четыре колонки: Входящие → В очереди → В работе → Готово; перетаскивание карточек; смена этапа на карточке |
| **Задачи** | Название, описание, вид и срочность, ответственный, срок, чек-лист, комментарии, история изменений |
| **Файлы** | Входящие материалы и итоговые документы к задаче (копируются в папку комнаты) |
| **Фильтры** | По срочности, виду задачи, «мои / чужие», поиск по тексту |
| **Сроки** | Календарь задач по датам выполнения |
| **Команда** | Начальник добавляет сотрудников; пароли на комнату и на учётные записи |
| **Начальник** | Сводка (нагрузка, просрочка, «зависшие»), отчёт «Просрочено», шаблоны задач, настройка видов и приоритетов |
| **Архив** | Выполненные задачи убираются с доски, файлы сохраняются |
| **Обмен** | Отдельное «окно» файлов для каждого сотрудника |
| **Тема** | Светлая и тёмная тема (настраивается на этом компьютере) |

## Установка программы {#установка-программы}

Для сотрудников офиса предусмотрена установка **только через установщик Windows** (файл `.exe`). Сборка и настройка для IT-отдела описаны в отдельной технической документации.

### Что понадобится

| Требование | Пояснение |
|------------|-----------|
| **ОС** | Windows 10 или 11 |
| **Права** | Разрешение на установку программ (обычно даёт администратор) |
| **Папка комнаты** | Общий доступ с правом чтения и записи для всех участников отдела |

### Установка с установщика

1. Получите файл **`RoomKanban Setup …exe`** (флешка, сетевая папка, почта — как принято в вашей организации).
2. Запустите установщик двойным щелчком.
3. При необходимости укажите папку установки и нажмите **Установить**.
4. После установки в меню **Пуск** и (если выбрано при установке) на рабочем столе появится ярлык **RoomKanban**.

Данные задач **не входят** в установщик — они всегда лежат в **общей папке комнаты**, которую вы укажете при первом запуске.

### Портативный вариант (без установки)

Если IT отдал **распакованную папку** с программой, запускайте **`RoomKanban.exe`** из неё. В систему ничего не записывается — удобно для проверки или временного использования.

### Обновление версии

Установите новый Setup поверх старой версии (или удалите старую через «Программы и компоненты» и установите заново). **Папку комнаты не трогайте** — все задачи и файлы останутся на месте.

### Первый запуск после установки

1. Запустите **RoomKanban**.
2. Выберите **Создать комнату** (если вы настраиваете отдел) или **Войти в комнату** / **Открыть комнату** (если папка уже создана).
3. Укажите **общую папку** комнаты (сетевой путь или синхронизируемая папка облака).

## Быстрый старт {#быстрый-старт}

### Первый запуск (начальник отдела) {#быстрый-старт-начальник}

1. Запустите программу.
2. Нажмите **Первый запуск** или **Создать комнату**.
3. Укажите папку (например, `D:\Офис\ЗадачиОтдела` или сетевой диск `\\server\share\Задачи`).
4. Введите **название комнаты**, **ваше имя и должность** — вы станете начальником этой комнаты.
5. При желании задайте **пароль на комнату** и **пароль своей учётки**.
6. Откроется канбан — можно создавать задачи кнопкой **+ Новая задача**.

### Подключение сотрудника {#быстрый-старт-сотрудник}

1. Начальник в разделе **Сотрудники** добавляет людей (имя и роль).
2. Все используют **одну и ту же папку** комнаты.
3. Сотрудник на своём ПК: **Войти в комнату** → та же папка → **выбрать своё имя** из списка (это не регистрация, а выбор уже созданного профиля).
4. При необходимости ввести пароль комнаты и/или личный пароль.

### Общая папка для всех {#быстрый-старт-папка}

Передайте коллегам **путь к папке** или доступ к сетевой шаре. Вход в программу всегда через **выбор этой папки** и **выбор имени** из списка сотрудников.

## Роли: начальник и сотрудники {#роли-начальник-и-сотрудники}

В каждой комнате один сотрудник — **начальник** (тот, кто создал комнату). Остальные — **сотрудники** с теми же правами на задачи, но без части настроек.

| Действие | Начальник | Сотрудник |
|----------|:---------:|:---------:|
| Создавать и редактировать задачи | ✓ | ✓ |
| Менять этап (колонку), перетаскивать карточки | ✓ | ✓ |
| Добавлять комментарии и файлы к задаче | ✓ | ✓ |
| Класть и забирать файлы в **Обмен** | ✓ | ✓ |
| Просматривать **Архив**, восстанавливать и удалять | ✓ | ✓ |
| Добавлять сотрудников, задавать пароли | ✓ | — |
| Настраивать виды задач и срочность (метки) | ✓ | — |
| Редактировать список **шаблонов** задач | ✓ | использовать при создании |
| **Сводка**, отчёт **Просрочено**, настройка напоминаний | ✓ | — |

### Начальник {#роль-начальник}

- Видит вкладки **Сводка** и **Просрочено**.
- Настраивает состав отдела, пароли, виды задач, приоритеты, шаблоны и напоминания о сроках.
- Удобно раз в неделю просматривать сводку и убирать выполненное в архив.

### Сотрудник {#роль-сотрудник}

- Работает с канбаном, календарём, обменом и архивом.
- При создании задачи может выбрать **шаблон**, если начальник их настроил.
- Не видит сводку и полный отчёт по просрочке (но видит подсветку просроченных карточек на доске).

## Разделы приложения {#разделы-приложения}

После входа в комнату вверху отображаются **вкладки**. Название комнаты и строка **Вы: …** — под вкладками; справа — **Обновить синхронизацию** и **Другая комната**.

| Вкладка | Кому доступна | Назначение |
|---------|---------------|------------|
| **Задачи** | Все | Канбан-доска |
| **Сроки** | Все | Календарь по датам выполнения |
| **Сотрудники** | Все (управление — начальник) | Состав комнаты, пароли |
| **Обмен** | Все | Файлы «в окно» каждого сотрудника |
| **Архив** | Все | Задачи, убранные с доски из «Готово» |
| **Сводка** | Только начальник | Нагрузка, просрочка, «зависшие», напоминания |
| **Просрочено** | Только начальник | Полный список просроченных активных задач |

### Шапка и переключение комнаты {#разделы-шапка}

- **Справка** и **F1** — это руководство.
- Переключатель **☀ Светлая** / **☾ Тёмная** — тема оформления.
- **Другая комната** — закрыть текущую комнату и выбрать другую папку или создать новую.

### Меню программы {#разделы-меню}

В строке меню Windows (если включена классическая строка меню у окна):

| Меню | Примеры действий |
|------|------------------|
| **Комната** | Сменить или создать комнату, закрыть текущую |
| **Вид** | Переход к календарю, сотрудникам, архиву, обмену; для начальника — сводка и просроченные |

Горячие клавиши из меню **Вид** (удобно запомнить начальнику):

| Сочетание | Раздел |
|-----------|--------|
| Ctrl+Shift+C | Сроки (календарь) |
| Ctrl+Shift+T | Сотрудники |
| Ctrl+Shift+O | Просрочено |
| Ctrl+Shift+D | Сводка |

## Канбан и задачи {#канбан-и-задачи}

Канбан — главный экран отдела. Задачи движутся слева направо по этапам работы.

### Колонки доски {#канбан-колонки}

| Колонка на доске | Смысл этапа |
|------------------|-------------|
| **Входящие** | Новое или на рассмотрении |
| **В очереди** | Запланировано к выполнению |
| **В работе** | Сейчас делается |
| **Готово** | Выполнено |

В заголовке каждой колонки:

- **+** — новая задача сразу в этой колонке;
- счётчик задач (при фильтре — «показано / всего», например `2/5`);
- выбор **сортировки** карточек (порядок сохраняется **на этом компьютере**, у коллег может быть другой).

В колонке **Готово** есть кнопка **В архив** — убирает все выполненные карточки с доски в раздел **Архив** (файлы не удаляются).

### Карточка задачи {#канбан-карточка}

На карточке видно:

- **название** задачи;
- **срочность** (цветная метка) и **срок** — просроченные подсвечиваются красным (кроме колонки «Готово»);
- **вид задачи** (письмо, звонок и т.д. — настраивает начальник);
- краткое **описание** и прогресс **чек-листа**;
- ссылки на прикреплённые **файлы**;
- выпадающий список **этапа** и кнопки **Подробнее** / редактирование.

**Перетащите** карточку в другую колонку или выберите этап внизу карточки — блокировка редактирования для этого **не** нужна.

### Создание задачи {#канбан-создание}

- Кнопка **+ Новая задача** — задача попадает во **Входящие**.
- **+** в заголовке колонки — сразу в выбранный этап.
- При создании можно выбрать **шаблон** (если начальник настроил шаблоны): подставятся название, описание и срок «через N дней».

### Шаблоны и метки (начальник) {#канбан-настройки}

| Кнопка на канбане | Действие |
|-------------------|----------|
| **Шаблоны** | Список типовых поручений для быстрого создания задач |
| **Виды и срочность** | Названия и цвета видов задач и уровней срочности |

### Одновременная работа над одной задачей {#канбан-блокировка}

Если коллега открыл задачу на **полное редактирование** (карандаш), остальные увидят сообщение вроде «Сейчас редактирует: …» и не смогут сохранить изменения полей. Блокировка снимается через несколько минут после закрытия окна или автоматически продлевается, пока редактор открыт.

**Комментарии** и часть действий в режиме **Подробнее** доступны без блокировки. Смена колонки перетаскиванием тоже не блокируется.

## Срок: дата и время {#срок-дата-и-время}

Срок задаётся в окне редактирования задачи: **дата** обязательна для контроля сроков в календаре и отчётах; **время** — по желанию.

| Как задан срок | Как это понимается |
|----------------|-------------------|
| Только **дата** | Срок — до **конца этого дня** (до 23:59) |
| **Дата и время** | Срок — к указанному моменту (например, 26 мая 2026, 14:30) |

На карточке и в отчётах дата показывается по-русски. Если время не указано, может отображаться пояснение вроде «до конца дня».

### Календарь {#срок-календарь}

- Задачи без срока **не попадают** в сетку месяца (их можно увидеть на доске и в фильтрах).
- Клик по **дню** — создать задачу с этим сроком.
- Просроченные незавершённые задачи в календаре выделяются **красным**.

### Просрочка и «Готово» {#срок-просрочка}

Задача считается **просроченной**, если момент срока уже прошёл и она **не** в колонке **Готово** и **не** в архиве.

Задачи в **Готово** **не считаются просроченными**, даже если срок был раньше — это сделано специально, чтобы выполненное не «кричало» красным.

Напоминания «срок сегодня» и «за N дней» сравнивают **календарную дату**, а не точное время (если время задано, день всё равно тот же).

## Фильтры и поиск {#фильтры-и-поиск}

На канбане нажмите **Показать фильтр** (или **Фильтр включён**, если фильтры уже активны), чтобы развернуть панель.

| Поле | Назначение |
|------|------------|
| **Поиск** | Название, описание, имя и роль ответственного |
| **Срочность** | Только задачи выбранного уровня срочности |
| **Вид задачи** | Метка типа (письмо, звонок и т.д.) |
| **Кому назначено** | Все задачи / только **мои** / **чужие** / конкретный сотрудник из списка |

При активном фильтре в заголовке колонки счётчик показывает **сколько видно из общего числа** (например, `2/5`).

Кнопка **Сбросить** убирает все фильтры сразу.

Фильтры действуют **только на вашем экране канбана** — коллеги могут смотреть доску без фильтров.

## Подробнее и редактирование {#подробнее-и-редактирование}

На карточке две основные кнопки:

| Кнопка | Режим | Что можно |
|--------|-------|-----------|
| **Подробнее** | Просмотр | Читать все поля, чек-лист, историю; добавлять **комментарии** и **файлы** |
| **Карандаш** (редактирование) | Полная правка | Менять название, описание, срок, ответственного, чек-лист, документы |

Окно **Подробнее** широкое: слева метаданные и описание, справа — документы, комментарии и история изменений.

### Если задачу редактирует другой {#подробнее-занято}

- Откройте **Подробнее** — можно оставить комментарий или приложить файл.
- Дождитесь, пока коллега закроет редактор, или согласуйте по телефону/чату, кто правит карточку.
- Если при сохранении программа сообщает, что на диске уже **более новая версия**, выберите: взять версию с диска или **сохранить свои правки поверх** (осторожно, если коллега тоже что-то менял).

### Поля в редакторе {#подробнее-поля}

| Поле | Назначение |
|------|------------|
| **Описание** | Постоянный текст задачи (ТЗ, детали) |
| **Срок** | Дата и при необходимости время |
| **Ответственный** | Кто ведёт задачу |
| **Вид и срочность** | Метки на карточке |
| **Чек-лист** | Подзадачи с галочками |
| **Документы** | Входящие материалы и итоговые файлы |
| **Комментарии** | Лента обсуждения по ходу работы |
| **История** | Кто и когда менял этап, срок, ответственного и т.д. |

## Архив задач {#архив-задач}

Вкладка **Архив** хранит задачи, которые убрали с доски из колонки **Готово**. Это не корзина Windows — это осознанное хранение выполненного с возможностью вернуть или удалить навсегда.

### Как задачи попадают в архив {#архив-как-попасть}

1. Переведите задачу в **Готово**.
2. В заголовке колонки **Готово** нажмите **В архив** — все карточки в этой колонке переедут в архив.

Файлы задачи при архивации **сохраняются**.

### Действия в архиве {#архив-действия}

| Кнопка | Результат |
|--------|-----------|
| **Открыть** | Просмотр как «Подробнее» — без правки основных полей |
| **Вернуть на доску** | Задача снова появится в колонке **Готово** |
| **Удалить** | Безвозвратно: задача, её файлы и история (с подтверждением) |

Периодически очищайте **Готово** через **В архив**, чтобы доска не превращалась в длинный список старых дел.

---

## Просроченные задачи {#просроченные-задачи}

**Просрочена** — задача, у которой **уже прошёл** срок, она **не** в архиве и этап **не** «Готово».

| Где видно | Что показывает |
|---------|----------------|
| Карточки на канбане | Красная подсветка срока |
| **Сроки** (календарь) | Красные метки в сетке |
| Вкладка **Просрочено** | Полный список (только начальник) |
| **Сводка** | Число просроченных и переход к списку |
| Счётчик на вкладке **Просрочено** | Сколько задач требуют внимания |

На канбане у начальника может быть кнопка быстрого перехода к отчёту **Просрочено**.

**Важно:** выполненная задача в **Готово** не считается просроченной, даже если срок был вчера.

## Обмен файлами {#обмен-файлами}

Раздел **Обмен** — это «окна» для каждого сотрудника комнаты. Сюда кладут файлы **без привязки к конкретной задаче**: скан, таблицу, письмо коллеге.

| Действие | Как сделать |
|----------|-------------|
| Положить файл сотруднику | В его карточке — **+ Добавить файл**, выбрать файлы с диска |
| Открыть файл | Клик по имени файла |
| Удалить один файл | **×** рядом с файлом |
| Очистить всё окно | **Очистить** (с подтверждением) |

Своё окно обычно выделено рамкой (**это вы**).

Любой участник комнаты может положить файл **любому** коллеге, в том числе начальнику.

Для документов по **конкретному поручению** удобнее прикреплять файлы в **задаче** (входящие / итоговые), а обмен — для быстрой передачи «вот файл тебе».

## Безопасность и пароли {#безопасность-и-пароли}

Пароли в программе **не хранятся открытым текстом** — только защищённый вид для проверки при входе.

| Пароль | Кто задаёт | Зачем |
|--------|------------|--------|
| **На комнату** | Начальник в **Сотрудники** | Чтобы человек с доступом к папке на диске не смог войти в программу без знания пароля |
| **На учётку сотрудника** | Начальник | Личный вход под выбранным именем |

**Самостоятельной регистрации нет:** начальник создаёт записи сотрудников, при входе человек **выбирает своё имя** из списка.

Рекомендации:

- Задайте пароль на комнату, если папка доступна многим на сервере.
- Личные пароли — для учёток начальника и тех, кто работает с чужого ПК.
- Не сообщайте пароли в общих чатах; лучше устно или через корпоративный канал.

## Напоминания о сроках {#напоминания-о-сроках}

Настраивает **начальник** в **Сводка** → блок **Напоминания о сроках**:

| Настройка | Пример |
|-----------|--------|
| За сколько дней напоминать | `1, 3` — за 1 и за 3 дня до срока |
| Кому показывать | Ответственному и/или начальнику |

Показываются **всплывающие уведомления Windows** на том компьютере, где открыта комната (проверка примерно раз в пять минут).

**Учтите:** ответственный увидит напоминание **только на своём ПК**, если у него тоже запущена программа с **той же папкой** комнаты. Если коллега не открывал приложение — напоминание на его экран не придёт; используйте обмен, почту или звонок.

## Тема оформления {#тема-оформления}

В шапке программы — переключатель **☀ Светлая** / **☾ Тёмная**.

- Выбор сохраняется **на этом компьютере** (у каждого сотрудника может быть своя тема).
- По умолчанию обычно включена **тёмная** тема.

Тема не влияет на данные комнаты и не синхронизируется с коллегами.

## Обновить синхронизацию {#обновить-синхронизацию}

Кнопка **Обновить синхронизацию** находится в панели комнаты (рядом с **Другая комната**).

**Когда нажимать:**

- коллега создал или изменил задачу, а у вас доска пустая или устарела;
- вы работали с папкой комнаты с другого компьютера;
- после долгого простоя программы или сбоя сетевой папки;
- если кажется, что не подтянулись новые файлы в **Обмен**.

Кнопка **заново читает данные** из общей папки комнаты: задачи, обмен, виды задач, срочность и шаблоны. Обычно изменения с другого ПК появляются **сами**; принудительное обновление — запасной вариант.

Во время обновления надпись может смениться на **Обновление…** — дождитесь окончания.

При изменениях с другого компьютера иногда появляется **краткое сообщение** в углу экрана — это нормально.

## Подсказки и справка {#подсказки-и-справка}

| Способ | Что делает |
|--------|------------|
| Иконка **?** рядом с подписью | Краткий текст при **наведении** курсора |
| **Клик по ?** | Открывает это руководство и прокручивает к **связанному разделу** |
| Кнопка **Справка** в шапке | Полный документ с оглавлением слева |
| Клавиша **F1** | То же, что **Справка** |
| Меню **Справка** (если есть) | Открыть руководство |

В окне справки можно **искать по оглавлению** и переходить между разделами.

Краткие тексты у **?** дублируют суть разделов — подробности всегда здесь, в полном руководстве.

## Частые вопросы {#частые-вопросы}

**Нужен ли интернет?**  
Нет. Нужен только доступ к **общей папке** комнаты (сеть или синхронизированное облако).

**Можно ли работать с одной копии папки на флешке?**  
Да, но **не вставляйте** флешку в два компьютера одновременно. Передавайте по очереди или используйте сетевую папку.

**Почему коллега не видит мою задачу?**  
Проверьте, что открыта **та же папка** комнаты. Нажмите **Обновить синхронизацию**. Убедитесь, что у всех есть **право записи** в папку и антивирус не блокирует файлы.

**Почему не могу сохранить задачу?**  
Возможно, её редактирует другой — используйте **Подробнее** для комментария или подождите. Либо на диске уже более новая версия — выберите, что сохранить.

**Задача в «Готово» подсвечена как просроченная?**  
Не должна. Выполненные задачи не считаются просроченными. Обновите программу до актуальной версии, если видите иначе.

**Где хранятся пароли?**  
В данных комнаты в защищённом виде, не как обычный текст в блокноте.

**Видны ли мои фильтры коллегам?**  
Нет. Фильтры и сортировка колонок — только на вашем ПК.

**Нужно ли каждый раз выбирать папку?**  
Программа запоминает последние комнаты на этом компьютере; можно быстро открыть недавнюю.

## Решение проблем {#решение-проблем}

| Симптом | Что проверить |
|---------|----------------|
| Пустая доска у одного ПК | Тот же путь к папке комнаты, права на запись, **Обновить синхронизацию** |
| Долго «Сейчас редактирует…» | Закрыть редактор на другом ПК или подождать несколько минут |
| Файл в обмене не виден | Та же комната, **Обновить синхронизацию**, права на папку |
| Ошибка при открытии комнаты | Папка не удалена и не переименована; восстановите из резервной копии |
| Дубликаты или «конфликт» файлов в облаке | Предпочтительна **одна** сетевая шара или один аккаунт синхронизации на отдел |
| SmartScreen при установке | Разрешите установку или обратитесь в IT (подпись издателя) |
| Нет уведомлений о сроках | Уведомления Windows включены; программа открыта с этой комнатой на нужном ПК |

Если задача «пропала» с доски — загляните в **Архив** и в колонку **Готово** с отключённым фильтром.

## Советы по работе в офисе {#советы-по-работе-в-офисе}

1. **Одна папка комнаты** на общий ресурс (например, `\\server\share\ЗадачиОтдела` или общая папка облака с полными правами для отдела).

2. Убедитесь, что **антивирус** не мешает записи в папку комнаты.

3. Обучите сотрудников: вход = **выбор папки + выбор имени** из списка, не копирование папки вручную на рабочий стол.

4. Начальник раз в неделю смотрит **Сводку** и **Просрочено**; выполненное убирайте **В архив**, а не копите бесконечно в **Готово**.

5. Для черновиков между людьми — **Обмен**; для работы с этапами и сроками — **задачи** на канбане.

6. **Резервная копия** — достаточно периодически копировать **всю папку комнаты** средствами IT (архиватор, robocopy, бэкап сервера).

7. Согласуйте, кто **редактирует** одну тяжёлую задачу в форме, а мелкие правки этапа — через перетаскивание на доске.

8. При работе через облако избегайте двух учётных записей, создающих **две копии** одной папки с разными именами.

## Ограничения {#ограничения}

- Только **настольная** программа для Windows — нет веб-версии и мобильного приложения.
- Нет встроенного чата и push на телефон — только **уведомления Windows** при запущенной программе.
- **Сортировка** карточек в колонках и **фильтры** на канбане — личные для каждого ПК, не общие для отдела.
- Смена этапа перетаскиванием **не проверяет**, открыт ли у кого-то полный редактор.
- При одновременной правке **одной и той же** задачи с двух ПК без согласования побеждает более поздняя сохранённая версия (в открытом редакторе можно выбрать вручную).
- Агрессивная синхронизация облака (конфликтующие копии файлов) может давать задержки — надёжнее стабильная **сетевая папка** или один аккаунт облака на отдел.
- Удаление сотрудника из списка **не переназначает** автоматически его старые задачи — проверьте ответственных заранее.
