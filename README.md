# RoomKanban

Настольное приложение для канбан-задач в офисе: общая папка вместо сервера, синхронизация через файлы.

## Документация

| Файл | Для кого | Содержание |
|------|----------|------------|
| [docs/USER_GUIDE.md](docs/USER_GUIDE.md) | Сотрудники, начальник | Как пользоваться интерфейсом: канбан, сроки, архив, обмен, FAQ |
| [docs/TECHNICAL.md](docs/TECHNICAL.md) | Разработчики, IT | Сборка, структура `sync/`, IPC, форматы JSON, npm |

**В приложении:** кнопка **Справка** или **F1** — две вкладки («Как пользоваться» и «Техническая»). Иконка **?** в интерфейсе открывает раздел руководства пользователя.

## Быстрый старт (разработка)

```bash
cd OficceHelper
npm install
npm run dev
```

## Сборка установщика Windows

```bash
npm run dist
```

Результат: `release/RoomKanban Setup 0.1.0.exe`. Иконка: `build/icon.png` (исходник — `assets/icon.png`).

## Скрипты

| Команда | Действие |
|---------|----------|
| `npm run dev` | Разработка |
| `npm run build` | Сборка в `out/` |
| `npm run dist` | Установщик `.exe` |
| `npm run typecheck` | Проверка TypeScript |

Подробности — в [docs/TECHNICAL.md](docs/TECHNICAL.md).
